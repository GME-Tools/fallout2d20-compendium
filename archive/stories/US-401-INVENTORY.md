## Reprints and corrections

The Issues #1–5 collection is a corrected re-edition rather than a literal
facsimile. Owner approval makes its mechanics canonical for issues 1–4 while
preserving the individual issue as `system.source`. The collection is recorded
as an identical secondary appearance of the resulting corrected document. No
superseded standalone-profile variant is published.

Errata V6 applies to the collection: scavenging in *Hunted!*, Scene Two:
Hunting Grounds uses the Red Rocket loot table on collection page 73. This is a
static scavenging control and creates no compendium record.

The collection's Robot Assassin table has overlapping printed ranges. Visual
review confirms `1–5`, `6–13`, `11–17`, `18–20`; owner-approved canonical ranges
are `1–5`, `6–10`, `11–17`, `18–20`.

## Artwork

Only owned official PDF artwork may be used. A publication cover or suitable
interior illustration may be shared by records for which it is genuinely
representative; otherwise the existing neutral type icon remains an explicit
placeholder. No generated, fan-made or web artwork is in scope.
