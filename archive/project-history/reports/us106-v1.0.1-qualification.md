## Rollback to V1.0.0

Do not execute this procedure as part of qualification:

1. Stop Foundry and take a complete backup of the Oracle/local User DataPath.
2. Preserve the V1.0.1 archive, manifest and qualification logs for diagnosis.
3. Download the immutable `v1.0.0` assets from the GitHub release, not the
   `latest` URLs, and verify that its manifest declares `1.0.0`.
4. Remove or move aside only the installed
   `Data/modules/fallout2d20-compendium` directory, then extract the V1.0.0
   archive at that exact location. Never merge two release directories.
5. Start a disposable copy of the affected world first on Foundry 14.367 and
   Fallout 11.17.1; confirm 40 packs, UUID resolution and representative import.
6. Only after that check, start the intended world. Restore the full DataPath
   backup if Foundry or another package performed an incompatible world
   migration. V1.0.1 performs no module content migration, ID rewrite or pack
   rename.
