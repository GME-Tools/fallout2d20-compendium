# US-401 — Astoundingly Awesome Tales

Integrate the reusable structured content from the seven numbered
*Astoundingly Awesome Tales* adventures in the existing categorical bilingual
packs. Issues 1 and 2 use their official French editions; issues 3–7 use a
reviewed project translation. Adventure prose, maps, scenes and pregenerated
characters remain outside compendium scope.

The 2024 Issues #1–5 collection is the owner-approved mechanical authority for
issues 1–4 while the individual issue remains the first publication. Identical
Core records are reused with secondary appearances. The collection-only fifth
adventure is first sourced to `astoundingly_awesome_tales_1_5`.

The reviewed inventory is [US-401-INVENTORY.md](US-401-INVENTORY.md). Completion
requires bilingual identity parity, valid provenance and links, exact French
metric conversion, reviewed artwork status, the additive AAT regression suite,
one final `npm audit --audit-level=high`, one final `npm run ci`, and disposable
Foundry 14.367/Fallout 11.17.1 qualification on loopback.
